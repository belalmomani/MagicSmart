# جهاز GDYM SMART_TV — ما أثبته الفحص الفعلي (2026-11-01)

| البند | القيمة |
|---|---|
| الشركة / العلامة / الموديل | GDYM / HiDPT / SMART_TV |
| النظام | Android 14 (API 34) — بناء **userdebug**، مفاتيح dev-keys |
| العتاد | Hi3751V352E (HiSilicon) — اللوحة bigfish |
| الإعدادات العامة والواي فاي | `com.cultraview.setting` (واجهة مصنّع) |
| بقية صفحات الإعدادات | `com.android.settings` (AOSP) |
| `com.android.tv.settings` | غير موجودة |
| خيارات المطوّر | غير مفعّلة؛ المسار الرسمي يقود إلى `DevelopmentSettingsDisabledActivity` |
| تصحيح USB / اللاسلكي | غير مفعّلان |
| خصائص ADB | `service/persist.adb.tcp.port=5555`، و`adbd` متوقف |
| قيود التصحيح (سياسة) | لا يوجد |
| Root / Shizuku / Device Owner | غير موجودة |

## ما يعنيه
- لا شيء يمنع التفعيل اليدوي: لا قيد سياسة، ومعلومات الجهاز (`MyDeviceInfoActivity`) متاحة لتفعيل خيارات المطوّر برقم البنية.
- مكوّنات المطوّر القياسية كانت تُصنَّف "غير موجودة" لأنها **معطّلة** حالياً (AOSP يفعّلها عند تفعيل الخيارات)؛ صُحّح الفحص ليميّز بين الحالتين.
- المنفذ 5555 مُعلن في الخصائص؛ يُرجَّح (لم يُتحقق) أن يفتح بعد تفعيل تصحيح USB. اختبار ADB-005 يتحقق من ذلك.
